## 3. Bases de datos y APIs

| Fuente | Qué aporta | Acceso |
|---|---|---|
| ETIM | Clases y atributos normalizados; formato ETIM xChange (JSON) | Gratis (Open Data Commons Attribution; xChange bajo Apache 2.0). Es esquema, no trae productos |
| ECLASS | Clasificación alternativa | Licencia paga [sin verificar] |
| EPLAN Data Portal | Macros, medidas y 3D por referencia | Consulta con cuenta Eplan Cloud gratuita; uso pleno ligado a licencia; créditos pagos para encargar artículos |
| TraceParts | CAD 2D/3D certificado por fabricante | Descarga gratis con registro; API Gateway por acuerdo, sin precio público |
| CADENAS 3Dfindit | CAD 3D de catálogos | Gratis con registro; integración con FreeCAD |
| Schneider | Product Catalog API v2 (especificaciones y documentos) | OAuth y alta por mail, orientada a distribuidores; gratis: PDF y CAD por referencia en se.com/ar |
| Siemens | SiePortal + CAx Download Manager (2D/3D, macros EPLAN) | Requiere cuenta y entrega por mail (según foros de soporte Siemens) |
| Octopart / Nexar | API GraphQL con especificaciones, hojas de datos y enlaces CAD | Plan Evaluation: 100 partes (1000 con mail corporativo); cobertura de marcas argentinas [sin verificar] |
| Argentina | Zoloda (fichas con medidas, par y corriente), BAW (manuales PDF), Genrod, Gabexel y Forli (catálogos PDF), Prodel, Electrocity, Distribuidores del Sud, LIESA, Mercado Libre (atributos y precio) | Sin API pública: carga manual o scraping |

Ninguna fuente gratuita cubre Taxnele, AG, Etheos, Jieli ni BAW. Estrategia: semilla manual (estas tablas), importador "pegar URL o PDF" y medición propia con foto y calibre como dato de mayor jerarquía; nombrar atributos según ETIM para no inventar esquema.

## 4. Campos de la ficha de componente

- **Identificación:** id interno, fabricante, referencia exacta, EAN, familia, descripción, clase ETIM, estado (vigente/discontinuado), sucesor, alias de taller.
- **Medidas:** ancho, alto, profundidad total y sobre riel, módulos DIN, peso, posición del eje de riel, huella 2D (SVG/DXF), modelo 3D (STEP/GLB o caja paramétrica), origen del dato (fabricante, distribuidor, medido) y fecha.
- **Eléctricos:** Ue, In o rango de regulación, curva, poder de corte, polos, bobina (tensión, frecuencia), contactos NA/NC, categoría de empleo, potencia disipada, IP.
- **Bornes:** uno por registro: nombre, cara y posición x/y/z, tipo (tornillo, túnel, push-in), sección mínima y máxima rígida y flexible, conductores por borne, par, largo de pelado, puntera y herramienta.
- **Reglas de montaje:** fijación (riel 35×7,5 o 35×15, placa, zócalo), orientación, separación lateral, superior e inferior, distancia a cablecanal, accesorios compatibles (auxiliares, peines, tapas, topes), derating por adosado.
- **Fotos y documentos:** frente, lateral, placa de características, foto con escala; hoja de datos, instructivo, certificado IRAM/IEC, URL fuente.
- **Comercial:** proveedor, código, precio, moneda, fecha, stock, mínimo, plazo, sustitutos.
- **Uso en proyecto:** prefijo de etiqueta (PE1-GMS1, PQ1-S1), función típica, plantilla de cableado, tiempo estándar de montaje.
